# ZipVault Pro Support

Thanks for using ZipVault Pro.

## Before reporting a problem

1. Make sure you are using the latest ZipVault Pro package you intend to use from this repository. Versions 1 and 2 remain available, while Version 3 is the current public release.
2. Test the same action on copied files when possible.
3. Note your ZipVault Pro version, Windows version, and the exact steps that caused the problem.
4. If the issue involves file moves, ZIP operations, cleanup, duplicates, or quarantine, keep the affected files and logs until the problem is understood.

## Report a bug

Open a GitHub Issue and include:

- ZipVault Pro version (V1, V2, V3, or a later public release)
- Windows version
- What you were trying to do
- What you expected to happen
- What actually happened
- Any error message
- A screenshot when useful

Please do not upload copyrighted ROMs, BIOS files, games, or other copyrighted content to an issue.

## Request a feature

Open a GitHub Issue and describe what you would like ZipVault Pro to do and how it would help your workflow.

## Safety reminder

ZipVault Pro can organize, copy, move, ZIP, unzip, quarantine, and clean up local files depending on the selected workflow. Test on copied files first and keep a backup of important collections.


## Update problems

If the built-in updater reports a problem, include the installed ZipVault Pro version and the exact update message in your GitHub Issue.

ZipVault Pro checks the official `updates/manifest.json` file in this repository. Only versions listed there are offered through the in-program updater.

Do not delete the **ZipVault Pro Backups** folder while troubleshooting an update, because it may contain the rollback copy created before files were replaced.
