# ZipVault Pro Support

Thanks for using ZipVault Pro.

## Before reporting a problem

1. Make sure you are using the current ZipVault Pro V1 package from this repository.
2. Test the same action on copied files when possible.
3. Note your Windows version and the exact steps that caused the problem.

## Report a bug

Open a GitHub Issue and include:

- Your Windows version
- What you were trying to do
- What you expected to happen
- What actually happened
- Any error message
- A screenshot when useful

Please do not upload copyrighted ROMs, BIOS files, games, or other copyrighted content to an issue.

## Request a feature

Open a GitHub Issue and describe what you would like ZipVault Pro to do and how it would help your workflow.
