# ZipVault Pro

**ZipVault Pro** is a Windows utility for organizing ROM and game-file collections. It provides ZIP tools, duplicate checking, ROM-extension support, game-title support, preview tools, and safety features to help users review and organize local game files more safely.

> **Important:** ZipVault Pro does not include ROMs, BIOS files, games, or emulators. Always test file-organizing operations on copied files before using your main collection.

## What ZipVault Pro Does

- Organizes Windows ROM and game-file collections
- Provides ZIP-file tools
- Helps check for duplicate files
- Supports ROM-file extensions and system-specific presets
- Supports game-title information and rename previews
- Provides preview tools before making changes
- Provides file-management actions such as Zip, Move, Copy, Zip+Move, and Unzip workflows
- Includes safety tools such as dry-run/preview options, ZIP verification, logs, undo information, and quarantine options
- Runs as a portable ZIP package

## What's New in Version 2

ZipVault Pro V2 keeps the core V1 workflow and expands it with additional tools, including:

- Expanded game-system presets and ROM-extension support across many retro and game platforms
- **Zip Loose Files**, **Move**, **Copy**, **Zip+Move**, and **Unzip/Unzip+Move** workflows
- Duplicate scanning with options such as **Keep Newest**, **Keep Biggest**, **Keep Existing ZIP**, and moving other copies to a Duplicates folder
- ZIP Health scanning and tools for identifying or moving bad ZIP files
- Cleanup tools for logs, quarantine, duplicate folders, empty folders, and temporary files
- Quarantine support for unknown or broken files
- Logs and undo CSV support
- Settings export/import and backup tools
- Preset management, including adding, updating, removing, scanning, and selecting saved system presets
- Game-title preview and naming controls
- Customization options for themes, fonts, layout size, and saved settings

## Quick Start

1. Choose **ZipVault Pro V1** or **ZipVault Pro V2** from the download links above.
2. Extract the ZIP file to a folder on your computer.
3. Keep `game title.zip` in the same folder as the application if the selected version uses it.
4. Run the included ZipVault Pro application.
5. Test the program on **copied files first** before using your main ROM or game collection.

## Who It Is For

ZipVault Pro is intended for Windows users who manage ROM libraries, retro-gaming collections, archived game files, or other game-related collections and want an easier way to organize, review, check, copy, move, ZIP, or clean up their files.

## Safety

ZipVault Pro works with files on your computer. Before using it on an important collection:

- Make a backup or work with copied files.
- Preview and verify results before making large changes.
- Keep an untouched copy of important ROM or game files whenever possible.

See the repository's [Security Policy](SECURITY.md) for additional safety information.
