# ZipVault Pro Changelog

This file tracks the public releases of ZipVault Pro.

## Version 2

Expanded Windows release of ZipVault Pro with additional organization, duplicate-management, cleanup, ZIP-health, preset, file-management, and customization tools.

### New and expanded features

- Expanded game-system presets and ROM-extension support
- Zip Loose Files, Move, Copy, Zip+Move, and Unzip/Unzip+Move workflows
- Duplicate scanning and duplicate-handling strategies
- ZIP Health scanning and bad-ZIP handling
- Cleanup tools for logs, quarantine, duplicate folders, empty folders, and temporary files
- Quarantine support for unknown or broken files
- Logs and undo CSV support
- Settings export/import and backup tools
- Preset management and scanning tools
- Game-title preview and naming controls
- Theme, font, layout, and settings customization

## Version 1

Initial public Windows release of ZipVault Pro.

### Included features

- ROM and game-file organization
- ZIP-file tools
- Duplicate checking
- ROM-extension support
- Game-title support
- Preview tools
- Portable ZIP distribution
